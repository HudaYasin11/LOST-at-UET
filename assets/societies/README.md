# Society logos and accounts

Store official society logos here, preferably transparent PNG or WebP files.
Use a stable filename matching the society ID, such as `music.png` or `aws.png`.
Do not substitute a parent organization's logo for its campus chapter's artwork.

Society records are in `data/societies.js`. Set `logo` to a path relative to the
page, for example `assets/societies/music.png`, and set `instagram` to the
society's confirmed HTTPS profile URL. Record the page that confirms the account
as `instagramSource`. Preserve the source of official artwork as `logoSource`.
Both fields remain `null` until supplied or verified. The page shows initials
when a logo is missing or fails to load, and no Instagram button for missing links.
